# ADR-012 v0.6 Implementation Diff

> 目标：把 v0.5 过度语义控制删除，同时尽量保留已经可靠的 Runtime 机械骨架。
>
> 基线：`homulillew/PaperSearch-Harness` branch `feat/adr12-v04-report-information-architecture`
>
> 实现原则：**删除 semantic machinery；保留 boring runtime machinery；只修已有 E2E 证明的 Runtime hole。**

---

## 1. Scope

本次实现只做：


```text

新的 report FSM

```

## 19. Implementation guardrails

实现中不得默认新增：

```text
new field
new enum
new quality rubric
new Reviewer
new score
new state
```

只有满足下面条件之一才重新讨论架构：

1. 一个真实 failure 没有任何现有 authority 有资格处理；
2. 某条 deterministic invariant 无法在现有 Runtime boundary 中表达；
3. 为了实现 v0.6 被迫创造新的独立 semantic truth。

否则选择更简单的实现。
