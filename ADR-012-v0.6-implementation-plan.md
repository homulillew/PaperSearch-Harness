# ADR-012 v0.6 — Implementation Plan

Architecture is **frozen**. This is an implementation task, not design.
Principle: remove semantic machinery; keep boring runtime machinery; only fix
runtime behavior with concrete failure evidence. Claude owns semantic judgment;
Python owns deterministic invariants; Research State stays the only research
authority.

## Step 2 — Change ReportBrief / Reader data types (reporting.py)

**Lean ReportBrief** (5 fields; replaces 9-field v0.5):
```python
@dataclass(slots=True, frozen=True, kw_only=True)
class ReportBrief:
    audience: str
    promise: str
    frame: str
    arc: tuple[str, ...]
    focus: tuple[str, ...]
```
- Delete: `BriefMaterial`, `ReportBriefSection`, `report_title`, `report_goal`,
  `conceptual_model`, `reader_takeaway`, `narrative_logic`, `sections`,
  `terminology`, `intentional_omissions`.
- `arc`/`focus` are non-empty tuples of non-empty strings (deterministic
  invariant only; no semantic move validation).

**ReaderIssue** (replaces `BlockingIssue` + `BlindBlockingIssue` +
`CognitiveFrictionObservation`):
```python
@dataclass(slots=True, frozen=True, kw_only=True)
class ReaderIssue:
    location: str | None = None
    observation: str
    reader_effect: str
    why_blocking: str
```
- No `repair_target` on the issue (Phase 1 has no attribution authority).
- No `resolution_condition` (that was semantic machinery).

**Lean BlindReadResult** (Phase 1):
```python
@dataclass(slots=True, frozen=True, kw_only=True)
class BlindReadResult:
    received_understanding: str
    manuscript_digest: str
    blocking_issues: tuple[ReaderIssue, ...] = ()
```
- Delete: `core_understanding`, `domain_model`, `comparison_coordinates`,
  `reverse_outline`, `material_economy`, `professional_finish`,
  `cognitive_friction`.

**Lean ReportReviewResult** (Phase 2 — carries the single repair target):
```python
@dataclass(slots=True, frozen=True, kw_only=True)
class ReportReviewResult:
    blind_read_digest: str
    brief_digest: str
    manuscript_digest: str
    repair_target: RepairTarget | None
    rationale: str
    blocking_issues: tuple[ReaderIssue, ...] = ()
```
- `repair_target` is top-level (not per-issue). `None` + empty issues = PASS.
  Non-`None` requires non-empty `rationale`.

**Shrink BriefRepairFeedback**:
```python
@dataclass(slots=True, frozen=True, kw_only=True)
class BriefRepairFeedback:
    problem: str
    resolution_condition: str
    location: str | None = None
```
- Delete `downstream_effect` (semantic machinery).

Keep: `RepairTarget` enum (`MANUSCRIPT`/`BRIEF`), `IntegrityDisposition`,
`ResearchIntegrityReview` (with `revise_target`), `ReaderPass`, `IntegrityPass`,
`CitationReference`, `ReportManuscript`, `DeliveryEvidenceAccess`,
`ReportCaptureSink`/`NoopReportCaptureSink`/`LocalReportCaptureSink`,
`BriefInsufficient`, `ReportResourceExhausted`, `ResearchEscalationRequired`.

Update `_validate_brief`, `_validate_blind_read`, `_validate_review_result`,
`validate_brief_repair_feedback` to match the new shapes. Remove
`reader_repair_target` helper (ReportReviewResult now carries the target
directly).

## Step 7 — Blind→Phase2 staged lock (certified_delivery.py)
In `_require_action_allowed` (or `submit_reader_review`): if a frozen
`blind_read` exists AND no `reader_review` is recorded yet, block semantic
mutation commands that would let Phase 2 paper over a blind FAIL. Concretely:
`submit-reader-review` is the only command that may follow a frozen blind read;
`put-report-manuscript`/`submit-blind-review` after a frozen blind read without
an intervening reader review is already blocked by `_clear_from` semantics, but
verify the invariant holds and add an explicit guard if a hole exists. (The
existing test `test_blind_failures_are_frozen_before_phase2_attribution` pins
this — keep it green.)

## Guardrails (§23)
Before adding any field/dataclass/enum/state/Reviewer/score/quality rule/
semantic layer, ask: *Is this necessary to implement an already-decided
authority boundary or deterministic invariant?* If not, do not add it. If a
genuine blocker appears requiring new authority/Gate/lifecycle/semantic IR/
state machine/score, STOP and report the concrete blocker.
