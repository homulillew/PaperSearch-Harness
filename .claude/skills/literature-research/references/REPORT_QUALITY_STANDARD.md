# 专业中文研究报告质量标准

> 版本：v0.5
> 适用范围：专业领域中文调研报告 / 技术路线综述 / Deep Research 报告  
> 目标：定义最终成品应达到的质量，而不是规定具体写作步骤或研究流程

---

## 1. 目的与边界

本标准定义：

> **一份面向真实专业读者的领域调研报告，作为最终成品，必须让读者获得怎样的理解。**

它关注最终报告的认知质量、论证质量、信息组织和语言品质。

它不负责：

- 判断研究是否已经完成；
- 决定 Research State 中什么结论可以成立；
- 规定 Authoring 的具体生成步骤；
- 规定 Reviewer 的具体审查流程；
- 计算统一的可读性分数、质量分数或 AI 风格分数。

各层职责如下：

```text
Research State
→ 决定报告可以陈述什么

Report Brief
→ 决定这一篇报告准备让读者怎样理解这些知识

Report Construction Guide
→ 指导 Constructor 把认知路径编译为可导航的文档层级

Report Writing Guide
→ 指导 Authoring 如何把认知路径实现为自然文章

Report Quality Standard
→ 定义最终成品应达到什么质量

Report Review Guide
→ 指导 Reviewer 如何发现没有达到标准的地方

Research Integrity Guide
→ 判断最终研究陈述是否忠实于 Research State 和 Primary Evidence
```

本标准描述的是**成品结果**，而不是固定模板。

因此不规定：

```text
固定章节数
固定段落数
固定论文数
固定表格数
固定列表数
固定字数
统一质量评分
```

专业报告的结构必须服从当前问题、目标读者和论证需要。

专业长报告还必须具备可扫描的信息架构。可理解性不等于可扫描性：即使全文顺读可以理解，如果专业读者不能通过标题树快速定位背景、主体、比较、开放问题和结论，交付质量仍然不足。文档层级应映射真正的认知层级，而不是材料数量、论文数量或排版装饰；本标准不规定固定标题数或固定 H4 数量。

## 2. 最高质量目标：读者理解

高质量专业领域中文调研报告，应当：

> **以最少的必要材料和最小充分认知链，使目标读者在合理认知成本下形成准确、连续、可复述的领域理解，并能够知道重要判断为什么成立、成立到什么程度，以及哪些问题仍然未知。**

报告的最终价值不在于展示：

- 搜索了多少论文；
- 阅读了多少来源；
- 覆盖了多少方法；
- 包含了多少实验数字；
- 使用了多少表格；
- 语言看起来多么正式。

最终应当回答：

> **读者读完之后真正理解了什么？**

一次正常阅读后，目标读者通常应能够：

1. 说明该领域正在解决的核心问题；
2. 建立理解主要路线所需的最小领域模型；
3. 说明主要技术路线之间真正重要的差异和联系；
4. 复述报告形成的主要判断；
5. 解释这些判断为什么成立；
6. 知道这些判断依赖哪些条件和限制；
7. 知道当前证据不能支持哪些更强结论；
8. 知道仍然存在的关键未知和开放问题。

如果文章包含大量正确内容，但读者读完后只能记住若干论文名、方法名和数字，而不能复述领域结构，则报告质量仍然失败。

### 2.1 局部清晰不能补偿全局理解失败

以下情况不能因为局部语言流畅而视为合格：

```text
每句话都能看懂
+
每节都局部完整
+
全文却无法形成稳定心智模型
```

同样：

```text
引用充分
+
事实正确
+
材料丰富
+
全文主要论证仍然无法复述
```

也不能视为高质量报告。

质量存在优先级：

```text
全局认知结构
>
局部段落漂亮

主要论证完整
>
语言形式流畅

读者理解
>
信息数量
```

## 3. 认知连续性

专业长报告不是若干独立知识块的集合。

读者在阅读过程中会持续维护一个不断更新的领域模型。

理想状态接近：

```text
M0
→ M1
→ M2
→ M3
→ ...
→ Mn
```

即：

> 前文建立的理解成为后文可以继续使用的认知基础。

报告不要求所有认识永远单调增加。新的证据可以修正前文的简化模型。

但这种修正必须显式发生：

> “前面的判断在条件 X 下成立；加入 Y 后需要进一步区分……”

而不能悄悄切换概念框架。

### 3.1 认知跳步

认知跳步指：

> 文章引入一个重要判断、比较或概念，但理解它所依赖的关键中间关系尚未建立。

例如：

```text
方法 A 减少成本 M
→ 因此系统瓶颈转向约束 C
```

如果报告没有建立：

```text
原始成本由哪些变量组成
→ 成本 M 降低后哪些约束仍然存在
→ 为什么约束 C 成为主要限制
```

读者就需要自行补足推理。

这属于认知跳步。

认知跳步不是要求所有显然事实都展开。

判断是否跳步取决于目标读者可以合理假设具备的前置知识。

### 3.2 认知重启

认知重启指：

> 新章节没有利用已经建立的读者认识，而是重新建立一个孤立的局部模型。

典型结构：

```text
路线 A
→ 从背景开始完整介绍 A

路线 B
→ 从背景开始完整介绍 B

路线 C
→ 从背景开始完整介绍 C
```

每一节可能局部清晰，但全文阅读不断要求读者：

```text
建立模型
→ 丢弃
→ 再建立
→ 再丢弃
```

高质量报告应尽可能让后面的内容继承前面的认知成果。

例如：

```text
前文已经建立：
总成本 = 单元数量 × 单元成本

下一节：
路线 X 改变单元成本

再下一节：
路线 Y 不改变单元成本，而改变单元数量
```

此时新路线是在已有模型上继续推进，而不是重新开始。

### 3.3 认知债务

认知债务指：

> 报告要求读者暂时记住尚未解释其意义、关系或用途的信息，并让这些未闭合信息持续累积。

常见来源包括：

- 连续出现多个方法名；
- 连续出现大量实验数字；
- 引入多个 benchmark 但尚未解释比较意义；
- 提前定义大量术语；
- 给出结论但延迟很久才解释依据。

少量暂时悬置是正常写作手段。

但如果读者需要长期维护大量：

```text
“这个之后会不会有用？”
“这个数字要和哪个数字比较？”
“这个术语为什么现在出现？”
```

报告会显著增加工作记忆负担。

高质量报告应尽快“消费”重要信息：

```text
材料出现
→ 解释它为什么出现
→ 建立当前判断
→ 完成当前认知任务
```

### 3.4 论证孤岛

论证孤岛指：

> 一段内容本身正确、甚至有价值，但无法说明它与全文主论证的关系。

例如：

- 突然介绍某篇代表论文；
- 给出一组很强的实验结果；
- 展开一个细节机制；

但后文既不使用它，也没有说明它改变了什么判断。

这类材料容易让报告表现为：

> 信息很丰富，但不知道为什么需要知道。

如果删除一段内容后：

- 当前判断不受影响；
- 后续论证不受影响；
- 读者心智模型不受影响；

则应重新判断它是否有必要存在。

## 4. Argument Completeness｜论证完整性

研究报告不能只告诉读者：

> “结论是什么。”

也不能只告诉读者：

> “论文和实验说了什么。”

重要判断必须形成可追踪的公开论证。

对于报告中的主要判断，读者通常应能够找到以下五类信息：

```text
1. 判断
   到底在主张什么？

2. 机制 / 原因
   为什么可能会这样？

3. 证据
   为什么有理由相信它？

4. 条件 / 限制
   在什么情况下成立，不能说明什么？

5. 含义
   这对当前问题、方法关系或领域理解意味着什么？
```

这些要素：

- 不要求机械出现在同一段；
- 不要求固定顺序；
- 不要求每个小结论都完整重复。

但全文的重要结论不能缺少其必要环节。

### 4.1 判断不能依赖作者语气成立

以下表达本身不构成论证：

```text
显然
值得注意的是
由此可见
总体来看
可以看出
```

如果删除这些措辞后，读者仍然不知道：

> “为什么？”

则论证没有建立。

### 4.2 证据必须被解释，而不是陈列

大量数字和论文并不会自动形成论证。

以下结构仍然可能失败：

```text
Paper A: +18%
Paper B: +24%
Paper C: 1.7x
Paper D: -35% resource use
```

如果读者不知道：

- 这些数字是否可比；
- 它们分别证明什么；
- 为什么足以支持当前判断；
- 哪些实验条件改变了解释；

则材料只是被陈列，没有进入论证。

### 4.3 重要限制必须进入论证，而不是附录式补充

如果一个结论的成立高度依赖：

- 模型规模；
- 硬件；
- 上下文长度；
- benchmark；
- 并发设置；
- 额外计算预算；
- 特定数据分布；

这些条件不能在结论之后以无关紧要的补充形式出现。

它们本身就是结论含义的一部分。

### 4.4 论证完整性不同于研究完整性

本标准判断：

> **文章是否让读者理解一个结论如何成立。**

Research Integrity Review 判断：

> **这个结论是否真的被 Research State 和 Primary Evidence 支持。**

二者不能合并。

一篇文章可能：

```text
研究上正确
+
文章中却没有解释清楚为什么
```

也可能：

```text
文章论证非常顺滑
+
实际已经超过研究证据
```

前者属于报告质量问题，后者属于研究完整性问题。

## 5. Material Economy｜材料经济性

高质量报告不是 Research State 的完整输出。

Research State 可以保存大量：

- 论文分析；
- 方法路线；
- 实验结果；
- 条件；
- 限制；
- 开放问题。

最终报告必须主动取舍。

### 5.1 正确不等于必须写

材料进入正文的理由不能只是：

```text
它是真的
它很重要
论文里有
Research State 里有
研究过程花了很多时间得到它
```

应当进一步回答：

> **它帮助读者完成了什么认知任务？**

一项材料通常至少承担以下一种功能：

### 建立

帮助形成一个新的重要认识。

### 区分

帮助区分两个容易混淆的方法、机制、条件或结论。

### 校准

通过条件、限制、反例、负结果或冲突证据，限制判断的强度。

如果一项材料没有明显承担任何认知功能，则应优先省略。

### 5.2 一个判断得到足够支持后，应停止堆叠同功能材料

例如一个代表性实验已经足以说明：

> 某路线在条件 C 下可以改善指标 M。

第二、第三、第四组结果只有在增加新的认知信息时才值得进入正文，例如：

- 展示另一种适用条件；
- 暴露反例；
- 说明泛化边界；
- 形成跨路线比较；
- 解释实验冲突。

否则只是增加阅读负担。

### 5.3 简洁不是字数少，而是没有认知闲置材料

一段复杂机制可能需要 500 字。

一个次要方法可能只需要一句。

因此本标准不使用：

```text
最大段落长度
最大数字数量
每节最大论文数
```

等机械阈值。

判断冗余的核心问题是：

> **删除以后，读者是否失去重要信息、比较或论证台阶？**

如果没有，优先删除。

### 5.4 研究完整性与材料经济性存在天然张力

Research State 倾向于：

> 不漏掉研究上重要的证据和限定。

最终文章倾向于：

> 不让所有正确材料同时占据读者注意力。

Report Brief 的重要职责之一，就是在不破坏研究语义的前提下完成这种有意识的舍弃。

## 6. Information Presentation｜信息呈现适配

正文、标题、列表、表格和图都是认知载体。

质量标准不规定必须使用哪一种形式。

成品只需要满足：

> **呈现形式应当与信息关系匹配，并降低而不是增加读者认知成本。**

### 6.1 连续关系应保持连续

如果内容本质上依赖：

- 因果；
- 递进；
- 转折；
- 条件；
- 推导；

呈现方式不能把这些关系拆碎到读者需要自己重新连接。

### 6.2 平行信息应便于扫描

多个真正独立、平行的条件、风险或结论，如果连续写成重复句式的大段正文，可能增加扫描成本。

成品应选择更适合快速理解其平行关系的形式。

### 6.3 横向比较必须具有共同坐标

当多个方法需要比较时，报告应让读者知道：

> 它们到底在哪些共同维度上被比较。

如果不同论文的：

- 模型；
- benchmark；
- 硬件；
- 推理预算；
- 上下文设置；

不能对齐，呈现方式不能通过视觉并列制造虚假的可比性。

### 6.4 呈现形式不能互相重复

以下情况通常属于质量缺陷：

```text
正文完整说一遍
+
表格再完整说一遍
+
结论又完整说一遍
```

同一信息可以在不同位置被重新引用，但应承担新的认知作用，而不是形式重复。

### 6.5 专业报告应同时支持连续阅读和快速定位

连续阅读时：

> 认知链应该持续推进。

重新查阅时：

> 重要判断应该可以通过标题、段首、表格或其他自然结构快速定位。

为了快速扫描增加结构，不能破坏全文论证连续性。

## 7. Professional Chinese｜专业中文成品质量

专业中文的核心不是：

- 复杂句；
- 大量正式词；
- 高频英文术语；
- 抽象名词密集；
- 公文式连接词。

专业感主要来自：

```text
概念准确
关系明确
条件完整
判断克制
信息具体
逻辑连续
```

### 7.1 语言不应成为额外理解障碍

最终文本应让目标专业读者主要把认知资源用于：

> 理解研究问题本身。

而不是用于：

> 解码句法、猜测主语、拆分长句、还原抽象名词之间的关系。

专业成品质量是 Reader PASS 的组成部分，不是独立 Style Gate。系统性 AI-like、翻译腔、
公文腔或机械节奏即使没有阻止强模型最终重建内容，只要已经使真实交付不再正式、成熟、
可信，就可以成为 blocker；单个惯用词或纯审美偏好通常不阻塞。

### 7.2 形式通顺不等于信息有效

例如：

> “该方法在提升系统整体性能方面具有较为显著的积极作用。”

语法可以完全正确，但信息贡献很低。

更专业的成品应该尽量说清楚：

```text
谁
改变了什么
在什么条件下
带来了什么结果
还有什么限制
```

### 7.3 模板化表达属于质量缺陷的症状，而不是独立评分项

以下模式如果反复出现，可能说明语言实现已经脱离内容逻辑：

- 每节使用相同开场；
- 每段都使用相同转折结构；
- 机械三点式、四点式；
- 大量无信息价值的“总体来看”；
- 过度使用“值得注意的是”“需要指出的是”；
- 不同章节长度与结构异常对称；
- 同一个判断被多次换词重述；
- 抽象名词替代具体动作；
- 英文论文句法被直接映射为中文。

但：

> **单个短语出现一次不是质量失败。**

只有当某种表达模式：

- 持续增加理解成本；
- 遮蔽真实逻辑；
- 造成明显机械节奏；
- 大量消耗篇幅却不增加认识；

才构成实质性问题。

### 7.4 去除“AI 化”不是模仿人类身份

本标准不要求：

> 让读者无法判断文章是否使用过 AI。

目标是：

> **消除模板化、空泛化、机械化等会降低专业阅读质量的生成特征。**

好的文本本身应当成立，而不是依赖“像不像人写的”作为唯一判据。

## 8. Global Closure｜全文闭合

长报告最终必须收敛。

结论不是重新列目录，也不是再介绍一次所有路线。

读者到达全文结束时，应能够看到：

> 前文建立的认识最终怎样组合成一个完整领域模型。

### 8.1 结论必须来自正文已经建立的结构

不应出现：

```text
正文从未建立的新分类
正文从未论证的新判断
正文从未解释的新因果关系
正文从未使用的新比较坐标
```

### 8.2 全文分类与概念关系必须保持一致

例如前文按照变量 X 对方法分类，结论又改为按照变量 Y 分类。

这不一定研究上矛盾。

但如果没有解释：

> 两套分类之间是什么关系，

读者会认为全文结构发生漂移。

### 8.3 开放问题必须从正文自然产生

好的开放问题通常来自：

```text
已有机制的已知限制
+
当前证据没有解决的部分
```

而不是在报告末尾额外附加一个与全文无关的“未来方向”列表。

### 8.4 全文应形成认知闭合，而不是信息耗尽

报告停止的原因不应是：

> “研究状态里的材料终于写完了。”

而应是：

> **报告承诺建立的主要认识已经形成，重要边界已经说明，继续增加材料不会实质改变读者理解。**

---

## 9. 阻塞性成品缺陷

本标准不使用统一质量分数。

如果存在足以破坏最终读者理解的具体缺陷，报告不能因为：

- 语言流畅；
- 引用很多；
- 信息丰富；
- 格式完整；

而被视为已经达到成品标准。

本标准不使用：

```text
可读性 7/10
专业度 8/10
AI 味 30%
```

等统一评分来替代具体成品质量判断。

### 9.1 认知结构失败

通常包括：

- 正常阅读后无法复述全文主要认识；
- 主要路线缺少稳定比较坐标；
- 重要判断之间存在关键认知跳步；
- 多个主要章节频繁认知重启；
- 大量内容形成论证孤岛；
- 读者需要长期承担明显认知债务；
- 前文建立的模型无法支持后文理解。

### 9.2 论证失败

通常包括：

- 重要判断缺少必要的成立过程；
- 机制、证据和结论之间关系不清；
- 大量证据存在，但读者不知道它们支持什么；
- 条件和限制没有进入主要判断；
- 重要比较依赖实际上不可比的实验结果；
- 结论依赖正文没有建立的中间推导。

### 9.3 材料与信息组织失败

通常包括：

- 大量正确但无必要认知功能的信息；
- 研究实体直接变成文章目录；
- 功能重复的论文和数字大量堆叠；
- 正文、表格、列表重复相同信息；
- 次要材料显著挤压主要论证；
- 呈现形式破坏信息之间真实关系。

### 9.4 表达失败

通常包括：

- 大量句子需要反复阅读才能理解；
- 句法持续遮蔽技术关系；
- 术语使用不稳定；
- 模板化表达大量替代真实逻辑连接；
- 段落局部流畅但全文节奏高度机械；
- 语言冗余显著增加认知负担。

### 9.5 全文闭合失败

通常包括：

- 结论切换分类体系却未解释关系；
- 结论引入正文未建立的重要认识；
- 开放问题与全文主要分析脱节；
- 重要问题被提出后既未回答，也未明确标记为未知；
- 全文结束后读者仍无法解释各主要部分为何属于同一个论证。

### 9.6 微小风格差异不是 blocker

以下情况本身通常不足以构成阻塞问题：

- 单个句子的个人偏好；
- 偶尔出现一个常见连接词；
- 某处可以稍微更简短；
- 另一种标题形式也可能同样合理；
- 不影响认知路径的轻微节奏差异。

这些微小差异只有在持续、系统性地增加认知成本，或实质破坏交付物要求的专业成品
质量时，才可能上升为 blocker。专业成品阈值不等于追求完美文风。

本标准关心的是：

> **真实理解失败或实质成品质量失败，而不是主观审美不一致。**

---

## 10. 自动质量保障与人类校准

自动化质量保障可以用于判断最终成品是否达到本标准，但机器审查通过并不等于真实人类接受。

> **机器质量保障证明的是当前自动审查协议没有发现阻塞性失败，不是所有真实专业读者都会获得相同体验。**

真实专业读者仍可能发现：

- 信息负担高于预期；
- 重点顺序不符合实际任务；
- 某些解释对真实受众仍然跳步；
- 某种模板化或机械化表达持续增加阅读成本；
- 自动审查能够自行补全、而真实读者无法补全的关系。

因此：

> **人类反馈是本质量标准长期校准的重要外部依据。**

当出现机器审查通过、但真实专业读者明确指出严重理解问题时，不应简单解释为“个人偏好”。应把该案例作为质量标准、审查指南、报告蓝图设计或写作实现的回归样本，判断现有标准是否漏掉了真实失败模式。

具体自动审查方法、盲读协议、反向提纲和故障归因方式由 `REPORT_REVIEW_GUIDE.md` 规定，不属于本成品质量标准。


# 最终原则

一份报告不会因为：

- 引用了很多论文；
- 包含很多实验数字；
- 有完整目录；
- 有多个表格；
- 语言正式；
- 局部句子流畅；
- 没有明显事实错误；

就自动成为高质量专业调研报告。

最终标准是：

> **目标读者能否沿一条连续而不过度压缩的认知路径，以合理认知成本建立准确、稳定、可复述的领域理解。**

研究阶段负责形成可信知识。

Report Construction 负责面向读者进行认知重构。

Authoring 负责将认知路径实现为自然、专业的中文文章。

Reader Review 负责验证文章是否真正作为人类认知载体成立。

Research Integrity Review 负责验证最终表达没有背叛研究状态和证据。

其中：

> **报告质量最终体现在读者获得的理解质量，而不是报告展示的信息数量。**
